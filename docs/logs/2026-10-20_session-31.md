## Ce qui a été fait
Relecture de tout le code, demandée par ademrepo : rien de trop, aucune ligne en surplus, un code qu'un étudiant aurait pu écrire. Le comportement et le rendu ne changent pas.

- `sokoban.py` :
  - `deplacer_joueur` et `pousser_caisse` répétaient le même code (case quittée par le joueur). Elles sont remplacées par une seule fonction `nouvelle_grille(r, c, dr, dc, pousse)` ;
  - `successorFunction` est plus courte : un `if` / `elif` (case libre / caisse), le mur n'a plus besoin d'un cas à part (il ne donne simplement pas de successeur).
- `gui.py` :
  - nouvelle fonction `sur_la_case` (image posée sur une case) : elle remplace les calculs recopiés pour la porte et l'arche ; la trajectoire utilise `ecran_case` au lieu de refaire le calcul ;
  - nouvelle fonction `poser_chat` (retourner le chat, ombre, pieds sur le bas de la case), utilisée par `dessiner_chat` et `dessiner_chat_sortie`, qui recopiaient ce code ;
  - `glisser(depart, arrivee, p)` sert maintenant aussi pour la marche vers la porte (le calcul était recopié) ;
  - `ecrire_ombre` sait centrer un texte (paramètre `centre`) : plus besoin de dessiner chaque titre une fois de plus juste pour mesurer sa largeur ;
  - menu : les trois tests `if choisie` sont regroupés en un seul ;
  - `draw` : deux tests opposés sur la phase `glisse` deviennent un seul `if` / `else` ;
  - `colonnes_max` et `lignes_max` deviennent de simples variables locales (elles ne servent que dans `__init__`).
- `assets_loader.py` :
  - la fonction `p()`, définie à l'intérieur de `creer_joueur`, devient une fonction normale `point(x, y, u)` ;
  - l'éclaircissement de l'herbe et des murs se fait dans une boucle au lieu de deux lignes recopiées ;
  - le chemin du dossier des images est coupé en deux lignes lisibles.
- `test_core.py` :
  - une seule fonction d'aide `lancer_bfs` (qui renvoie le nœud et les steps) au lieu de deux qui relançaient chacune le BFS ;
  - `test_bfs_solution_rejouee_arrive_au_but` est supprimé : `test_bfs_resout_tous_les_niveaux` rejoue déjà la solution de tous les niveaux. Sa vérification en plus (longueur de la solution = coût) est passée dans ce test. Il reste 16 tests.
- `docs/EXPLICATIONS.md` : noms de fonctions et nombre de tests mis à jour.
